# Changelog

## Unreleased

BorrowdaleJS is in early development. The workspace packages currently use version `0.0.0` and are not yet published to npm.

The local website includes an editable playground, three open-data examples, shared documentation, and project information pages. These notes describe the development workspace, not a published release.

Cartesian charts now include interval marks, connected numeric paths and confidence bands, symbols and trusted image markers, opt-in labels, annotations, weighted categories, bar shapes, segment styles, tapered trails, crossing fills and gradients. The playground includes 33 additional editable compositions, including waterfall, bullet, Pareto, dumbbell and variwide charts.

Once packages are published, each package's release notes are generated from its changesets into its own `CHANGELOG.md`, and this file will link to them. The [GitHub commit history](https://github.com/borrowdale/borrowdale/commits/main/) records source changes.
