# Changelog

## Unreleased

BorrowdaleJS is in early development. The first release, 0.1.0, is in preparation: the four packages share one version and are released together, and used in Node.js they need version 22 or later. Until then the workspace packages use version `0.0.0` and are not published to npm.

The website in `apps/site` includes an editable playground, three open-data examples, shared documentation and project information pages. It is built from the development workspace, not from a published release.

Once packages are published, each package's release notes are generated from its changesets into its own `CHANGELOG.md`, and this file will link to them. The [GitHub commit history](https://github.com/borrowdale/borrowdale/commits/main/) records source changes.
