# About BorrowdaleJS

BorrowdaleJS brings a hand-drawn visual language to charts, shapes, text and repeating patterns. It is named for Borrowdale in the English Lake District, associated with the graphite used in early pencil making.

## Precise data, expressive marks

A drawing can feel informal while preserving its scales and data. BorrowdaleJS combines measured text, chart layout and seeded drawing primitives so the same input can produce repeatable output.

The toolkit is written in TypeScript. Public package names use the `@borrowdale` scope: `core`, `charts`, `text` and `fills`.

## What you can explore

The playground contains individual reference examples with editable code. The examples section combines charts into complete dashboards using saved public datasets from the World Bank, NASA GISS and USGS.

BorrowdaleJS is still in early development and has not been published to npm. The website runs from the local workspace. Start with the [documentation](README.md), or read how to [contribute](../CONTRIBUTING.md).
